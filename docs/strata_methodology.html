Updated 2026-08-09: the diagram above is Phase 1 (OSM discovery), run in small polite chunks now instead of one query per stratum. Strata are processed sequentially (STRATUM_WORKERS=1 — reduced from an earlier 6-way concurrent attempt that combined with a per-candidate logging bug to stall a run at 26+ hours; sequential is what's actually confirmed to work reliably). Two more phases run after Phase 1, only for strata where they make sense — Phase 2 densify (tile a 7x7 grid, 48 new points, around every accepted anchor, for 10 strata whose real-world footprint is a large contiguous zone: Industrial, Dense Urban, Suburban, Industrial+Water, Urban+Coastal, Agrivoltaics, Industrial+Arid, Industrial+Forest, Suburban+Agricultural, Informal+Urban) and Phase 3 GHSL seed (sample points inside real satellite-measured Urban Centre polygons, independent of OSM tagging — Dense Urban, Suburban, Informal+Urban; the latter two are region-restricted to match their Phase 1 scope, after a live run caught false positives — Atlanta GA, Guangzhou China — from searching globally with no restriction). All three phases share this exact same unmodified gate — the region restriction only changes which candidates get proposed to it, not the gate itself. See docs/scale_ceiling_analysis.html for the confirmed final counts: 245,530 total, completed in 10h 56m 44s once both bugs above were fixed.
